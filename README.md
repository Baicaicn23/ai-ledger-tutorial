# 《从零开始构建 AI 记账助手》教学文档

> 一个 Python + Agent 的全栈小项目：带你从「用 AI」走到「造 AI 应用」。

## 这本教程是什么

2025 年被很多人称为「Agent 元年」：大家关心的不再只是模型本身有多聪明，而是能不能让模型**动手做事**——查数据、调接口、读写文件。市面上讲 Agent 原理的文章很多，但真正有一个完整、可运行、代码量可控的小项目可以拆开揉碎来讲的却不多。

这本教程以本项目「小账本」为标本，带你完整走一遍一个 AI 原生应用的诞生过程：需求怎么想、数据怎么存、接口怎么设计、智能体的「思考—行动」循环怎么跑起来、界面怎么做、出了问题怎么查。我们坚持**先把东西跑起来，再理解它为什么能跑**——每一章都对应仓库里真实存在的文件和代码，学完一章就能验证一章。

## 你将收获什么

- 真正理解 **Agent 与普通聊天机器人的区别**：模型 + 工具 + 循环
- 掌握 **Function Calling（函数调用）** 的完整机制，能手写调用循环而不依赖任何 Agent 框架
- 用 **FastAPI + SQLite** 写出干净可用的后端接口
- 做出一个有设计感的 **浅色「纸感账本」前端**（无框架、无构建步骤）
- 学会 **联调排错**：Key 配置、端口冲突、依赖安装、日志定位
- 拿到一条清晰的 **毕业设计路线**：从记账助手扩展到预算提醒、报表、语音、多智能体

## 如何阅读

1. **对照源码读**：每个代码片段都来自 `ai-ledger/` 下真实文件，边读边打开对照。
2. **跟着做练习**：每章末尾有「小结」和「练习」，练习都不大，但当堂动手效果最好。
3. **先跑再看**：如果某一节暂时看不懂，先把项目跑起来，回头再看代码会更具体。
4. **边做边教**：本教程假设你愿意理解「为什么」，而不只是复制粘贴——关键设计都会解释动机和取舍。

## 项目结构

```
ai-ledger/
├── app.py            # FastAPI 路由：接口层
├── agent.py          # DeepSeek Agent：工具调用循环
├── db.py             # SQLite 存储：数据层
├── static/
│   ├── index.html    # 页面结构
│   ├── style.css     # 浅色纸感样式
│   └── app.js        # 前端逻辑
├── setup.sh          # 一键安装依赖
├── start.sh          # 一键启动
├── requirements.txt  # 依赖清单
├── .env              # API Key 配置（不要提交）
└── docs/             # 你正在读的这本教程
```

## 先修要求

- 会一点 Python 基础语法（函数、字典、异常）
- 会用终端执行命令（cd、运行脚本）
- 不需要任何 AI / 量化 / 后端框架经验
